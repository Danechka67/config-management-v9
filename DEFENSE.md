# Как разобраться в проекте перед защитой

1. `src/main.py` читает аргументы, загружает CSV в VFS и открывает окно.
2. `src/gui.py` получает строку по Enter, показывает ввод и передаёт строку
   в `Shell.execute`. Этот же путь используют команды стартового скрипта.
3. `src/shell.py` делит строку методом `split`: первое слово — команда,
   остальные — аргументы. Словарь `commands` выбирает обработчик.
4. `src/vfs.py` хранит словарь: абсолютный путь → Node. В Node есть тип
   и байты содержимого. Вложенность задаётся путями и проверкой родителей.
5. `src/removal.py` проверяет аргументы и удаляет записи словаря.
   Записи на диск нет. Перезапуск повторно читает исходный CSV.

## Короткая демонстрация

Откройте терминал в папке проекта и запустите `python -m src.main`.
Введите в графическом окне:

```text
ls
cd /docs/course/week1
ls
 tail -n 2 notes.txt
cd /
date
rm /hello.txt
ls
tail /hello.txt
exit
```

Пробел перед `tail` допустим: парсер игнорирует лишние пробелы.
Снова запустите программу и введите `ls`: hello.txt снова появится.
Так можно показать, что rm изменяет только память.

Для демонстрации продолжения после ошибки:
`python -m src.main --startup examples/commands.txt`.
В журнале после неверных команд видны результаты последующих команд.

## Что нужно уметь объяснить

- Почему GUI и логика команд разделены: команды можно тестировать без окна.
- Почему base64: CSV — текстовый формат, а содержимое файлов бывает двоичным.
- Почему cd не вызывает os.chdir: меняется каталог виртуальной системы.
- Почему путь `/docs` не относится к настоящему каталогу на компьютере.
- Чем ошибка команды отличается от exit: ошибка возвращает текст,
  exit меняет running на False и GUI закрывает окно.
- Почему сохранены пять коммитов: методичка требует истории каждого этапа.

и сценарии запуска на своей машине.
